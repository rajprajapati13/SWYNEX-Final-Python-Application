# SWYNEX Final Python Application

## Student Record Management System

A menu-driven Python application to manage student records.

## Features
- Add student records
- View all students
- Search students by roll number
- Delete student records
- Validate user input
- Handle file and JSON errors
- Store records in a JSON file

## Technologies Used
- Python
- JSON
- pathlib

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python student_manager.py
```

## Data Storage
Student records are saved in `students.json`. This file is created automatically when a student is added.

## Learning Outcomes
Learned Python functions, loops, conditional statements, file handling, JSON, input validation, and error handling.
